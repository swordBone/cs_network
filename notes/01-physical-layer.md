# 物理层：信号、编码与信道容量

> 来源：第 2 章课件 PDF 第 4—52 页；`note2.pdf` 第 2 页。前置知识：[网络性能与分层](../week1.md)。

## 1. 物理层负责什么

物理层研究如何在介质上传输比特流，并尽量向链路层屏蔽不同介质的差异。网线、光纤是传输介质；物理层是有关接口和信号传输的规则及实现，不能简单等同于“网线”。

| 接口特性 | 回答的问题 | 例子 |
| --- | --- | --- |
| 机械 | 接口长什么样 | 插头形状、针脚数、固定方式 |
| 电气 | 信号如何用电学量表示 | 电压范围、阻抗、速率限制 |
| 功能 | 各信号线做什么 | 发送、接收、地线、准备就绪 |
| 过程 | 事件以什么顺序发生 | 建链、发送、应答、撤销 |

消息是可传递的内容；数据是消息的表示；信号是承载数据的物理量。数字数据既可编码为基带信号，也可调制到载波上传输。

## 2. 传输方式是不同维度的分类

| 分类维度 | 类型 | 区别 |
| --- | --- | --- |
| 比特的时空排列 | 串行 / 并行 | 逐位发送 / 多条通路同时发送 |
| 通信方向 | 单工 / 半双工 / 全双工 | 单向 / 双向交替 / 双向同时 |
| 连接范围 | 点到点 / 点到多点 | 两端通信 / 多节点共享连接 |
| 是否搬移频谱 | 基带 / 频带（通带） | 不搬移到载波频带 / 调制后搬移 |

这些分类可以组合，例如“串行、全双工、点到点”。串行也能高速，不能仅凭“每次一位”判断它必然比并行慢。

## 3. 从波形到频谱：为什么带宽会限制速率

适当条件下，周期 $`T`$ 的信号可以分解为基波与谐波。采用如下记号：

```math
g(t)=c+\sum_{n=1}^{\infty}\left[a_n\sin(2\pi nt/T)+b_n\cos(2\pi nt/T)\right]
```

```math
c=\frac1T\int_0^Tg(t)\,dt,\quad
a_n=\frac2T\int_0^Tg(t)\sin(2\pi nt/T)\,dt,\quad
b_n=\frac2T\int_0^Tg(t)\cos(2\pi nt/T)\,dt
```

**纠偏：** 课件第 13 页把常数项写为 $`c`$，第 15 页却给出 $`2/T`$ 的积分系数；两者不能同时使用。常数项为 $`c`$ 时取平均值 $`1/T`$；若写作 $`a_0/2`$，才有 $`a_0=(2/T)\int g(t)dt`$。课件第 17 页的 $`c=3/8`$ 与前一种约定一致。

数字波形的尖锐跳变需要较多高频分量。有限带宽信道削弱高频分量，接收波形因此失真；若码元过密，相邻波形会相互干扰，形成码间干扰（ISI）。

课件中的 8 bit 周期例子：若 $`R_b`$ bit/s，每 8 bit 重复一次，则

```math
T=8/R_b,\qquad f_0=R_b/8,\qquad N_{\max}=\lfloor f_c/f_0\rfloor.
```

这里的 $`N_{\max}`$ 是截止频率内允许的最高谐波阶数，不保证每一阶的系数都非零。提高比特率会使基频升高，同一信道能保留的谐波阶数减少。

## 4. 比特率、码元率与编码

| 量 | 符号 | 单位 | 含义 |
| --- | --- | --- | --- |
| 频率带宽 | $`W`$ | Hz | 频谱占用的宽度 |
| 比特率 | $`R_b`$ | bit/s | 每秒传送的比特数 |
| 码元率 | $`R_s`$ | Baud，即码元/s | 每秒发送的符号数 |
| 可区分符号数 | $`M`$ | 无量纲 | 星座点数或电平级数 |

固定长度映射、忽略纠错和其他冗余时，$`M=2^q`$ 个符号每个可携带 $`q=\log_2M`$ bit：

```math
R_b=R_s\log_2M.
```

64-QAM 的每个符号携带 6 个映射比特。若加入码率为 $`r_c`$ 的纠错码，有效信息速率还要乘 $`r_c`$，并扣除导频、首部等开销。

### 基带编码

| 编码 | 本课件约定 / 做法 | 理解重点 |
| --- | --- | --- |
| NRZ | 用两个电平表示 0、1 | 长串相同位缺少跳变，不利于时钟恢复 |
| Manchester | 位中必跳变；低到高为 0，高到低为 1 | 跳变提供同步；题目可能采用相反映射，应先确认约定 |
| NRZI | 每位开始逢 1 跳变、逢 0 不变 | 用变化表示信息；其他协议也可能采用不同约定 |
| 4B/5B | 4 个数据位映射成 5 个编码位 | 增加冗余，限制不利于同步的位串；还需要线路编码 |

在课件以“半比特电平单元”为码元的 Manchester 计数下，2 个这样的单元表示 1 bit，故 $`R_s=2R_b`$。不能把两个电平都当作可独立携带 1 bit 的符号。

### 载波调制

对 $`A\sin(2\pi ft+\varphi)`$，ASK 改幅度，FSK 改频率，PSK 改相位；QAM 使用正交的 I/Q 分量组合幅度与相位。星座点越多，每个符号携带的比特越多，但在相同平均功率下，可靠地区分相邻点也更困难。

## 5. 奈奎斯特与香农：先看模型，再代公式

### 奈奎斯特：理想无噪声低通信道

对带宽为 $`W`$ 的理想低通模型，采用合适的无码间干扰脉冲：

```math
R_s\le2W,\qquad R_b\le2W\log_2M.
```

例如 $`W=3000`$ Hz，8 电平编码，每个码元携带 3 bit：

```math
R_b\le 2\times3000\times3\,\mathrm{bit/s}=18000\,\mathrm{bit/s}=18\,\mathrm{kbit/s}.
```

这里限定了电平数；在完全无噪声且能无限精确地区分电平的抽象模型中，单靠该公式无法给出与 $`M`$ 无关的比特率上限。

### 香农：带限加性白高斯噪声信道的容量

```math
C=W\log_2(1+S/N).
```

$`S/N`$ 是**线性功率比**。若题目给分贝值：

```math
\mathrm{SNR}_{dB}=10\log_{10}(S/N),\qquad S/N=10^{\mathrm{SNR}_{dB}/10}.
```

`note2.pdf` 中的例题：$`W=3000`$ Hz，SNR = 30 dB，则

```math
S/N=1000,\quad C=3000\log_2(1001)\approx29901.7\ \mathrm{bit/s}.
```

容量是可可靠通信速率的理论界限；“改进编码”可以帮助逼近它，不能在固定带宽、固定信噪比和相同信道模型下突破它。

若题目同时使用有限电平低通模型和噪声容量限制，应同时满足两项约束：

```math
R_b\le\min\{2W\log_2M,\ W\log_2(1+S/N)\}.
```

反求带宽时取下界的较大者；这只是必要约束，不等于证明某种实际调制一定能达到目标误码率。

### 64-QAM 题目的带宽口径纠偏

`note2.pdf` 给出 $`R_s=R_b/6`$，这一步正确；随后用低通公式得到 $`W=R_b/12`$。需要补上模型条件：

- **64 个实电平的理想低通题**：$`W\ge R_b/12`$。
- **64-QAM 的实际通带宽度**：I、Q 是两个正交分量，不能把 64 个星座点直接当作单路 64 电平。升余弦成形、滚降系数 $`\alpha`$ 时，通带占用宽度为 $`W_{RF}=(1+\alpha)R_s=(1+\alpha)R_b/6`$；理想零滚降下为 $`R_b/6`$。相关成形与符号映射见 [MathWorks 的 QAM 脉冲成形说明](https://www.mathworks.com/help/comm/ug/use-pulse-shaping-on-16-qam-signal.html)与[升余弦滤波说明](https://www.mathworks.com/help/comm/ug/raised-cosine-filtering.html)。

若按手写题采用的简化低通模型，且 SNR 固定为 20 dB，则

```math
W\ge\max\{R_b/12,\ R_b/\log_2(101)\}=R_b/\log_2(101).
```

若问零滚降 64-QAM 的通带宽度，则还需 $`W_{RF}\ge R_b/6`$，它比 $`R_b/\log_2(101)`$ 更严格。实际系统还取决于滚降、编码与目标误码率。原笔记没有完整题干，不能把其最后一行当作通用 QAM 结论。

## 6. 信息量与性能指标

自信息 $`I(x)=-\log_2p(x)`$。等可能的 $`M`$ 种结果完全确定一种，需要 $`\log_2M`$ bit 信息。例如已知 27 个球中恰有一个更重，用天平每次最多区分三种结果，至少需要 $`\lceil\log_3 27\rceil=3`$ 次称量。

不要混淆信号传播速度与比特率。传输时延 $`L/R_b`$ 表示把一帧送入链路的时间，传播时延 $`d/v`$ 表示信号走完链路的时间；推导停等性能时会同时用到两者。

## 自测与答案

1. 2400 Baud、16 个符号、无冗余时比特率是多少？**9600 bit/s。**
2. 20 dB 的线性信噪比是多少？**100，不是 20。**
3. $`W=4`$ kHz、4 电平、SNR = 15（线性），简化模型上限？**奈奎斯特与香农均给出 16 kbit/s。**
4. 增大信号传播速度一定提高信道容量吗？**不能这样推断；传播时延与容量是不同量。**
5. 改进编码能突破香农容量吗？**在同一模型、带宽与信噪比下不能。**
