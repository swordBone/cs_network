# 传输介质与多路复用

> 来源：第 2 章课件 PDF 第 53—123 页；`note2.pdf` 第 1 页。先读[信号与带宽](01-physical-layer.md)。

## 1. 介质决定信号传播的物理环境

| 类型 | 例子 | 主要特点与限制 |
| --- | --- | --- |
| 导引型 | 双绞线 | 绞合帮助减小干扰；衰减、串扰影响质量，距离与速率要结合具体制式 |
| 导引型 | 同轴电缆 | 芯线、绝缘、外导体屏蔽；用于有线电视等系统 |
| 导引型 | 光纤 | 光导波，容量高、抗电磁干扰；受损耗、色散、器件能力影响 |
| 导引型 | 电力线 | 复用已有线路，但负载变化与电器噪声影响信道 |
| 非导引型 | 无线电、微波 | 便于移动或远距离覆盖；受干扰、多径、遮挡、频谱资源限制 |
| 非导引型 | 红外、自由空间光 | 方向性强；遮挡、对准和天气可能影响连接 |

“数字数据”不限定必须使用某种介质；铜线、光纤、无线都可以承载数字通信。

### 光纤

纤芯折射率高于包层；几何光学模型中，合适入射角下的全反射使光被约束在纤芯内。

- 多模阶跃光纤：不同传播路径带来明显模式色散。
- 多模渐变光纤：折射率逐渐变化，减小不同路径的时延差。
- 单模光纤：只传播一个空间模式，避免多模间色散，但仍有其他色散与损耗。

“单模”不等于“只能传一个波长”；单模光纤也可使用 WDM。课件的某个光电器件速率例子不能当作所有光纤系统的速度上限。

### 卫星通信

GEO 静止轨道高度约 36000 km；地面站经卫星到另一地面站要走上、下行两段。若忽略斜距、处理等，仅按 $72000$ km 路径估算：

$$d_{prop}\approx72000/(3\times10^5)=0.24\ \mathrm{s}.$$

这是一次地面站到地面站传输的传播时间，往返还要约翻倍。课件停等例子取单程 270 ms，因而往返传播为 540 ms。

低轨卫星距离较近，通常有利于降低传播时延，但覆盖区移动，需要星座、切换和跟踪。课件中的卫星数量、商业规划是材料当时的例子，本笔记不将其作为实时数据。

**纠偏：**光在空气或真空中传播得比在玻璃中快，主要影响传播时延；不能仅凭这一点推导“激光链路比光纤的比特率更高”。

## 2. 为什么复用

复用允许多路信号共享传输资源；发送端合并，接收端按规则分离。关键是建立可区分的频率、时间、波长、码或空间维度。

| 方式 | 划分依据 | 核心特点 |
| --- | --- | --- |
| FDM 频分 | 不同频带 | 同时传输；通常需要保护带 |
| TDM 时分 | 固定周期时隙 | 时隙位置标识用户；无数据时也可能占空时隙 |
| STDM 统计时分 | 按需分配时隙 | 适合突发数据；需标识归属、缓冲与调度 |
| WDM 波分 | 不同光波长 | 光域中的频分复用 |
| CDM / CDMA 码分 | 不同码序列 | 可共享时间和频带，通过相关运算区分 |
| OFDM 正交频分 | 正交子载波 | 将高速流拆成并行低速流，使用 IFFT/FFT 实现 |
| SDM 空分（补充） | 不同空间通道 | 如不同光纤、空间波束或可分离的空间流 |

复用强调多路信息如何组合；多址强调多个用户如何共享资源，两者相关但不是完全相同的术语。OFDM 本身也不意味着每个子载波一定分给不同用户。

### TDM 与 STDM 的例子

4 个用户每周期各占 1 个时隙，只有 A、C 有数据：

```text
固定 TDM： [A][空][C][空] [A][空][C][空]
统计 TDM： [A][C][A][C] ...（需能识别各数据的归属）
```

STDM 减少空时隙，但不创造容量；总到达速率长期超过输出速率时，仍会排队或丢弃。固定 TDM 中，若每周期 $T$ 秒、每用户获 $q$ bit，其平均份额为 $q/T$ bit/s。

## 3. CDMA：用内积提取用户数据

把 0、1 码片映射成 $-1,+1$。每个用户分配长度为 $m$ 的码片向量。理想同步、等幅、正交模型满足：

$$\frac1mS\cdot S=1,\qquad\frac1mS\cdot T=0\quad(S\ne T).$$

用户发送 1 时发 $S$，发送 0 时发 $-S$，不发送时贡献零向量。若接收叠加向量为 $Y$，用户 S 的判决量为

$$z_S=\frac1mY\cdot S.$$

理想模型中 $+1$ 表示发送 1，$-1$ 表示发送 0，0 表示未发送。码片不同还不够，必须满足相应的相关性质；实际噪声、不同步和功率差会影响结果。

### 课件第 107 页例题

```text
A = (-1,-1,-1,+1,+1,-1,+1,+1)
B = (-1,-1,+1,-1,+1,+1,+1,-1)
C = (-1,+1,-1,+1,+1,+1,-1,-1)
D = (-1,+1,-1,-1,-1,-1,+1,-1)
Y = (-1,+1,-3,+1,-1,-3,+1,+1)
```

计算得到 $(Y\cdot A,Y\cdot B,Y\cdot C,Y\cdot D)=(8,-8,0,8)$。除以 8，判定 **A、D 发 1，B 发 0，C 未发送**。还可以反向验证 $Y=A-B+D$。

若每个信息比特扩展为 $m$ 个码片，信息速率为 $R_b$，则码片速率为 $mR_b$ chip/s。码片数增加的是传输冗余及扩频程度，不是用户有效信息量。

直接序列扩频（DSSS）使用高速码片序列；跳频扩频（FHSS）按约定序列切换载频。

## 4. OFDM：为什么调制对应 IDFT

宽带单载波的符号较短，多径传播产生的时延差可能跨越多个符号。将数据拆成 $N$ 路低速流后，每个子载波上的符号变长，更便于处理多径。

### 正交的含义

设有效 OFDM 符号时间为 $T_u$，子载波间隔 $\Delta f=1/T_u$。对 $k\ne l$：

$$\int_0^{T_u}e^{j2\pi(k-l)t/T_u}\,dt=0.$$

所以子载波频谱虽然可以重叠，在正确同步和理想条件下，接收端仍能在一个有效符号区间内将它们分离。正交不等于“频谱互不重叠”。

### 连续表达式与离散采样

令 $X[k]$ 为第 $k$ 个子载波上的复数调制符号，采样间隔 $T_s=T_u/N$。采用带 $1/N$ 系数的 IDFT 约定：

$$x[n]=\frac1N\sum_{k=0}^{N-1}X[k]e^{j2\pi kn/N},\qquad n=0,\ldots,N-1.$$

这就是 IDFT；接收端用 DFT 恢复 $X[k]$。IFFT/FFT 是快速计算这些变换的算法，不是另一种变换。课件省略 $1/N$ 是归一化约定不同，只要收发端一致即可。

**纠偏：**课件第 121 页把 $x_l$ 称作“第 l 个 OFDM 符号”。更准确地说，$x[n]$ 是**一个 OFDM 符号内部的第 n 个时域采样点**；这一组 $N$ 个点共同表示一个有效 OFDM 符号。

```mermaid
flowchart LR
    A[比特流] --> B[串并转换与 QAM/PSK 映射]
    B --> C[N 路频域符号]
    C --> D[IFFT]
    D --> E[时域采样与发射]
    E --> F[信道]
    F --> G[同步与接收采样]
    G --> H[FFT]
    H --> I[均衡与符号判决]
    I --> J[恢复比特流]
```

补充：实际系统通常还需要保护间隔或循环前缀、导频、同步和均衡；只做 IFFT 并不自动消除所有多径干扰。循环前缀占用时间，也会降低净数据效率。

## 自测与答案

1. WDM 与 FDM 的关系？**WDM 是光域中用不同波长实现的频分复用。**
2. CDMA 内积为 0 是“发送了 0”吗？**在上述理想模型中是未发送；发送 0 得到 -1。**
3. OFDM 发射端用 FFT 还是 IFFT？**常见约定为 IFFT，接收端 FFT。**
4. 固定 TDM 的用户暂时没有数据会怎样？**预分配时隙可能空闲。**
5. 一个 OFDM 符号有 64 个 IFFT 输出点，它包含 64 个先后发送的 OFDM 符号吗？**不是，这些点属于同一有效符号。**
