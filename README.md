## 复习时先检查这几件事

1. 带宽的单位是 Hz 还是 bit/s？QAM 使用的是低通还是通带带宽？
2. 信噪比给的是 dB 还是线性功率比？
3. CRC 余数为零只能说明未检出错误；检错与纠错是两回事。
4. ACK 表示“已收到的帧”，还是“下一帧的期望序号”？
5. GBN 的 $`2^k-1`$ 与等窗口 SR 的 $`2^{k-1}`$ 不要混淆。
6. PPP 有链路协商与差错检测，但基本 PPP 数据传输不提供 ARQ 可靠交付。
